# DevSpace 权限与能力修复（2026-10-29）

范围：用户授权先处理方案 2–7。暂缓方案 1（Studio 路径重整）及方案 8（三机发布）。不迁移、不复制业务项目。

## 已实现

- 所有公开文件修改按目标文件版本检查，无关文件改变不拦整个项目。读取版本存入 SQLite，重连后继续保护同一文件；命令执行不再依赖整个目录的完整指纹。
- 修正 grep include→glob 映射；inspect_files 提供稳定结果快照与游标；read_page 按字节完整读取，返回版本、偏移、base64，不再因超长单行无法继续。
- start_task、list_tasks、task_status、task_log、task_input、cancel_task：独立后台进程、持久日志、断线找回、不自动重跑、按任务预算执行。显式状态未知时保留现场。活动命令仍持有工作区写锁；读取不受影响。
- Mac 附件用系统 Python 3 的 dir_fd/openat/linkat 操作实现，路径和文件身份检查后无覆盖发布。Linux 保留原实现。
- export_artifact 返回指定成品的不可变副本及限时单文件下载链接。过期链接失效，后续导出清理过期副本；不会导出整个项目。
- copy_file、move_file、make_directory 支持普通文本及二进制文件；复制移动目标必须不存在；没有加入递归删除。
- 仓库安装复用已有 Git 凭据，保持交互提示关闭；支持 npm、pnpm、Yarn、uv 锁文件；安装脚本按具体任务显式选择。没有新建账号或开通付费服务。
- Bridge 及 AIBOS 的源码修改在各自仓库单独记录。

## 验证

- DevSpace npm test 全套通过；typecheck、build 通过。
- 620 条内容搜索分页，无漏项和重复；UTF-8 大文件按字节还原一致。
- 正常工作区无关文件变化可继续修改；同一文件外部变化被阻止；SQLite 会话重建后仍保护目标，重新读取可恢复。
- 后台任务完成 310 秒命令，跨发起进程退出与 DevSpace 重启恢复，完整日志一致。
- Mac 实机验证附件、目标冲突、符号链接、大小限制、临时文件清理及权限。
- 成品下载验证快照稳定、链接到期、未知令牌拒绝；二进制复制移动验证无覆盖和路径边界。

## 运行边界

- 现阶段部署只针对 Pro；Studio、MSI 不在本轮发布范围。
- 后台任务的活动写锁用于防止未知命令和文件工具互相覆盖，不是授权降级。任务失联时不猜测已经停止，不重复执行。
- read_page 的单次字节上限、搜索单页上限只是分页大小，可连续取完；任务日志同理。
- export_artifact 的链接是限时单文件访问能力，应只用于用户要求交付的成品。
- Mac 附件依赖 /usr/bin/python3；不支持的系统会明确报错，不会退回不安全路径写入。
- 文件移动复制当前面向普通文件；目录用 make_directory，未提供递归目录迁移。
- AIBOS 仍执行后台 grant 校验，写工具不会给只读 OAuth scope 自动扩权。
